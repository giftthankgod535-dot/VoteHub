VoteHub – Online Voting System
About the Project

VoteHub is an online voting system developed to provide a convenient and organized platform for conducting elections. It allows registered students to participate in elections and view voting results.
Technologies Used

HTML

CSS

PHP

MySQL

JavaScript
Features

Student registration and login

Secure student voting

Candidate registration and application

Admin dashboard

Election creation and management

Candidate approval

Real-time election results
Database

VoteHub uses a MySQL database to store student records, election details, candidate information and voting records.
Developer
